# 模块2 · AI 队友

核心实现在 `__init__.py`，负责队友小夏、阿澄、小墨的角色配置、公开对话推理、重复问题检查和演示线索。三名队友分别侧重细节观察、因果推理和反例验证。

接口：`propose_question(client, surface, history, teammate=None) -> str`。teammate 为 `id/name/focus` 角色信息；仅接收公开汤面与问答记录，不接收汤底、评分事实、数据库连接或整个游戏对象。共用模型客户端来自 `code/llm.py`。

合作模式默认两位 AI，可选择1至3位。每轮玩家提问后，按阵容顺序让每名队友各提问一次，再回到玩家。全部队友共享有发言者身份的公开问答，避免重复提问；未配置独立私有记忆。演示模式每题共有四条线索，用完即交还玩家。每位队友的一次远程回合包含提问和判题各一次请求。

线索耗尽抛出 `DemoCluesExhausted`；模型错误抛出 `ModelError`。回合控制、失败重试与记忆持久化由模块3负责。本模块不操作浏览器、HTTP 或数据库。

协作时主要修改本目录；接口变更需同步根目录 `contracts.py`、`engine.py` 及相关测试。
