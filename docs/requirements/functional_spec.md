# 软件系统功能规格说明书

## 1. 系统角色 (Actor)

### 1.1 人类角色

·玩家：阅读汤面、向 AI 汤主提问、与 AI 队友协作推理、请求提示并提交最终答案。

·系统管理员：维护题库与系统配置，查看异常日志，处理违规内容与运营数据。

### 1.2 智能体角色 (Agent Roles)

|编号|智能体|职责|主要输入/工具|
|---|---|---|---|
|AG-1|AI 出题器 (PuzzleGeneratorAgent)|生成汤面、汤底、关键事实、难度与提示；检查题目逻辑完整性|主题、难度、内容规范、LLM|
|AG-2|AI 汤主 (HostAgent)|掌握汤底，对玩家问题稳定回答“是/不是/无关”，避免直接泄底|汤底、玩家问题、问答历史|
|AG-3|AI 队友 (TeammateAgent)|仅根据公开线索与问答历史参与推理、提出问题、整理线索、给出渐进提示|汤面、历史问答、线索集|
|AG-4|内容审核智能体 (SafetyReviewAgent)|审核题目正向性、敏感内容、逻辑冲突与答案泄露风险|内容安全规则、题目与对话记录|


## 2. 功能树 (Feature Tree)

### 2.1 游戏与会话管理模块 (Game Session)

·FR-1.1：玩家可创建新游戏，并选择题目主题与难度（简单/普通/困难）。

·FR-1.2：系统创建游戏会话并绑定唯一题目、问答历史、线索列表与状态。

·FR-1.3：玩家可结束当前游戏并查看完整汤底与复盘结果。

### 2.2 AI 题目生成模块 (Puzzle Generation)

·FR-2.1：AI 出题器根据主题、难度生成汤面、汤底、关键事实、关键线索与三级提示。

·FR-2.2：生成内容必须保持正向、健康，避免血腥、色情、极端暴力与恶意诱导等不适宜内容。

·FR-2.3：题目生成后须通过逻辑一致性与可解性检查；未通过时自动重新生成，最多 3 次。

·FR-2.4：系统可将通过审核的优质题目保存至题库，支持后续复用。

### 2.3 AI 汤主问答模块 (Host Q&amp;A)

·FR-3.1：玩家以自然语言输入问题，AI 汤主结合汤底判断并回答“是 / 不是 / 无关”。

·FR-3.2：对于表述模糊、包含多个判断的问题，系统应提示玩家拆分问题，不直接给出误导性结论。

·FR-3.3：AI 汤主回答必须与既有汤底和历史回答保持一致；检测到冲突时应以原始汤底为准进行纠正。

·FR-3.4：AI 汤主不得主动泄露汤底、关键答案或未被玩家询问的决定性线索。

### 2.4 AI 队友协作模块 (Teammate Reasoning)

·FR-4.1：AI 队友只能读取汤面、公开问答历史和已确认线索，不得直接访问汤底。

·FR-4.2：AI 队友可基于现有信息提出下一步问题或推理方向，且应避免高频抢答。

·FR-4.3：AI 队友可总结“已确认 / 已排除 / 待验证”信息，帮助玩家整理推理结构。

·FR-4.4：玩家请求帮助时，AI 队友按三级提示机制提供由弱到强的提示。

### 2.5 游戏复盘模块 (Review)

·FR-7.1：游戏结束后展示完整汤底、关键线索和推荐推理路径。

·FR-7.2：统计提问次数、有效问题数、无关问题数、提示次数与完成轮数。

·FR-7.3：生成简短复盘建议，例如“人物关系判断较快，但时间线验证不足”。

### 2.6 内容安全与管理模块 (Safety &amp; Administration)

·FR-8.1：内容审核智能体对新题目执行正向性、敏感内容与逻辑一致性审核。

·FR-8.2：管理员可查看题目、会话异常和审核日志，并下架不合规题目。

·FR-8.3：所有 Agent 调用应记录任务类型、耗时、状态与异常信息，便于问题追踪。


## 3. 典型业务流程（摘要）

1.玩家进入游戏，选择主题与难度，创建新的游戏会话。

2.AI 出题器生成汤面、汤底、关键事实和提示，并由内容审核智能体进行安全与逻辑检查。

3.系统仅向玩家、AI 队友展示汤面；汤底只对 AI 汤主与答案判定模块可见。

4.玩家提出自然语言问题，AI 汤主依据汤底返回“是 / 不是 / 无关”。

5.AI 队友读取公开历史，适时提出推理建议或新问题，并整理当前线索。

6.玩家卡关时可主动请求提示；系统按由弱到强的等级提供帮助。

7.玩家提交最终答案，系统对照关键事实判断完整度；通过后展示完整汤底。

8.系统生成本局复盘，包括关键线索、提问统计与推理建议，并保存游戏结果。


## 4. 验收标准（摘要）

·能够从“创建游戏”顺利完成到“提交答案并查看复盘”的完整闭环，无阻断性错误。

·标准测试中，AI 汤主对明确可判断的问题应稳定输出“是 / 不是 / 无关”，且不得出现与汤底相冲突的关键回答。不能泄露题目。

·AI 队友在正常游戏中不得直接读取或泄露汤底、不应重复问题。

·自动生成题目必须包含汤面、汤底、关键事实和提示，并通过内容安全与逻辑一致性检查后才可进入游戏。

·玩家结束游戏后能够查看完整汤底、关键线索和基础统计信息。

AI 服务出现一次临时失败时，系统应保留当前会话数据，并支持重试而无需重新开始整局。
